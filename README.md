# Not Defteri — Obsidian eklentisi

Öğrenci notlandırma: artı / eksi / gelmedi tıklamalı takip, özet tablo ve öğrenci kartı
(T.C., aile, sağlık, akademik durum, KVKK izinleri, özel notlar).

## Kurulum (BRAT ile)

1. Obsidian'da **BRAT** eklentisini kur (Community plugins → Browse → "BRAT").
2. `Ctrl+P` → **BRAT: Add a beta plugin for testing**.
3. Yapıştır: `yasirbilgic/not-defteri`
4. **Add Plugin** → BRAT eklentiyi indirir ve etkinleştirir.
5. Güncelleme için: `Ctrl+P` → **BRAT: Check for updates to all beta plugins**.

## Manuel kurulum

Bu deponun **Releases** bölümünden `main.js`, `manifest.json`, `styles.css` dosyalarını indir ve
`.obsidian/plugins/not-defteri/` klasörüne koy. Obsidian'ı yeniden yükle.

## Sürüm

`manifest.json` içindeki `version` ile release tag'i eşleşmelidir.
